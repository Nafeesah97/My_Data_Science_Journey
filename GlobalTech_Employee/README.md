# 🌐 GlobalTech Solutions Workforce Analysis
**Author:** Naffisat Salaudeen
**Date:** 2025-10-11  

---

## Project Overview
This project analyzes the workforce and compensation data of **GlobalTech Solutions** to answer key business questions and provide insights for the **Company Workforce & Compensation Dashboard**.  

Focus areas include:  
- Employee tenure and distribution  
- Salary patterns and comparisons  
- Departmental and city-level insights  
- Retention and risk indicators
